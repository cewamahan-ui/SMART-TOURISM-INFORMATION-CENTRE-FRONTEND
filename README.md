# SafariSmart Frontend

## Quick Start

Follow these steps to set up and run the application locally:

1. **Clone the repository:**

  ```bash
  git clone <REPO_URL>
  cd SMART-TOURISM-INFORMATION-CENTRE-FRONTEND

```

2 **making it run in your computer**
git pull origin feature/screens- it will show you there are conflicts so run the following after

 git pull --no-rebase

 git pull origin feature/screens- pulling changes from the feature screens

git pull origin feature/screens --allow-unrelated-history

git switch feature/screens







2. **Install dependencies:**

  ```bash
  npm install

  ```
if it will not run do npm audit fix


3. **Set up environment variables:**

  If a `.env.example` file exists, copy it:

  ```bash
  cp .env.example .env
  ```
   
  Otherwise, create a `.env` file and add:

  ```env
  VITE_API_BASE_URL=http://localhost:5000
  ```

4. **Run the development server:**

  ```bash
  npm run dev
  ```

5. **Open your browser:**

  Visit [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal) to view the app.

---

A modern React frontend for the Smart Tourism Information Centre experience, built with TanStack Router + Vite.

It includes:
- Public exploration flows (explore, itinerary, transport, accommodations, bookings)
- Kiosk-first landing and preferences flow
- Favorites and notifications screens
- Authentication screens (login/register/profile/settings)
- Multi-language UI support
- Backend API integration through a centralized client

## Tech Stack

- React 19
- Vite 7
- TanStack Router + TanStack Query
- Tailwind CSS 4
- Radix UI + custom UI primitives
- Lucide icons

## Project Structure

```text
src/
  components/        Reusable UI and layout pieces
  hooks/             React hooks (e.g. mobile breakpoint detection)
  language/          i18n provider and locale dictionaries
  lib/               API client, auth context, utilities
  routes/            File-based route pages
  routeTree.gen.js   Generated by TanStack Router
tsr.config.json      TanStack Router generator settings
```

1. Install dependencies:


## Routing Notes

This project uses TanStack file-based routing.

Important:
- `src/routeTree.gen.js` is generated directly by TanStack Router.
- Routing generation behavior is configured in `tsr.config.json`.

## API Integration

Main API client lives in `src/lib/api.jsx`.

- Base URL comes from `VITE_API_BASE_URL`.
- Access token is stored in local storage (`sts_access_token`).
- The client supports JSON payload helpers and normalized error handling.

The client includes modules for:
- auth
- destinations and attractions
- itineraries and bookings
- transport
- payments
- kiosk sessions and operations
- favorites, users, audit, and admin endpoints

## Internationalization (i18n)

Language support is implemented with:
- `src/language/i18n-provider.jsx`
- `src/language/locales/*`

Supported locale dictionaries include English, Swahili, French, and German.

## Troubleshooting

- Route issues after edits:
  - Restart `npm run dev` to refresh generated route artifacts.
- Backend not reachable:
  - Check `VITE_API_BASE_URL` and ensure backend is running.
- Menu/layout weirdness during active dev reload:
  - Hard refresh browser after major layout refactors.
